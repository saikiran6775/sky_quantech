# Sky Quantech AI — Marketing Website

Nine-page static marketing site. The visual design came from Google Stitch and is
**approved and frozen**: do not redesign, restyle, or introduce another design
language. Work is content, correctness, accessibility and performance.

## Build

```bash
node site/build.mjs      # assemble dist/ from site/
node tools/pipeline.mjs  # re-derive site/pages/ from the Stitch export, then build
```

There is no dev server; serve `dist/` statically:
`python3 -m http.server 8099 --directory dist`

## Layout

- `site/data/site.mjs` — nav, company, services, industries, process, SEO, contact
  placeholders. **Single source of truth**; never hard-code these in a page.
- `site/data/forms.config.mjs` — form submission endpoint. Currently `null`.
- `site/theme/tailwind.theme.mjs` — the one Tailwind token set, injected into every
  page. Generated by merging the Stitch configs; brand palette is authoritative.
- `site/partials/` — `head`, `header`, `footer`, `form-contact`, `form-careers`.
- `site/pages/<slug>.html` — page content only (no header/footer/nav).
- `site/assets/` — `logo.png`, `site.js`, `forms.js`, `img/` (localized Stitch images).
- `tools/` — the transforms that produced `site/pages/` from the export.
- `dist/` — build output. Generated; never edit by hand.
- `stitch_sky_quantech_ai_website/` — the original export. Reference only.

## Rules

- **Never edit `dist/`.** Change `site/` and rebuild.
- **Never duplicate nav or footer.** They live in `site/partials/` and are rendered
  once per page by the build, with `aria-current` set from the page slug.
- **Never invent company facts.** No certifications, metrics, client names, job
  openings, social accounts, history or headcount. Contact details are
  client-supplied and live in `site/data/site.mjs`; the build substitutes them
  into page bodies, so never hard-code them. No social accounts exist yet.
- **Palette is fixed:** deep blue `#001060`, dark blue `#001070`, primary
  `#0020A0`, electric `#0050F0`, bright `#0060F0`, highlight `#0078FF`, white,
  light blue `#F5F8FF`. No teal, purple, orange or rainbow gradients.
- **Type is fixed:** Plus Jakarta Sans for headings, Inter for body.
- Forms must not fake success. `forms.js` reports honestly when no endpoint is set.
- **Contrast corrections** live in `site/partials/head.html`. The export reused
  container tokens (`secondary-container`, `on-tertiary-container`) as text
  colors, which failed WCAG AA. `site/theme/dark-sections.mjs` stamps
  `data-on-dark` / `data-chip-light` at build time so those rules scope by
  context. Match class tokens exactly — a substring selector also catches
  `hover:` variants and breaks base states.
- The export references color tokens no config defined (`brand-*`, `accent-blue`,
  `ice-blue`). They are in `site/theme/tailwind.theme.mjs`; a missing one renders
  as invisible text, so add rather than remove.

## Verifying changes

Build, serve, then use `/browse`. The checks that matter: no console errors, no
horizontal overflow at 375/768/1440, no broken images, every internal link
resolves, one `<footer>` and one `<h1>` per page, and form validation shows
inline errors. Compare against the sibling `screen.png` in the Stitch export
when touching layout.
